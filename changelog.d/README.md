# Fragments de nouveautés

Un fichier `.md` par contribution visible par les joueurs, nommé `sujet-court-ab12.md`
(suffixe aléatoire : le nom doit être unique, jamais celui de la branche, jamais un
fragment existant). Une phrase par ligne, en français courant, 130 caractères au plus,
sans vocabulaire technique ; `#` commence un commentaire. La version affichée est
calculée depuis Git. Voir [docs/changelog.md](../docs/changelog.md).
